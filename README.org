This is a fork of the CRAN package monotone, which has an excellent C
library of "legacy" PAVA algorithms, all implemented with the same
interface: [[file:src/legacyC.c]]

* New features in fork

This fork is a research project, in progress, with code and results in [[https://github.com/tdhock/sparse-label-positions][sparse-label-positions]] and [[https://github.com/D4EM3ON/pool-party][pool-party]].

** Iteration counting

The original monotone package legacy C functions in [[file:src/legacyC.c]] have three arguments (n, x, w).

This forked =monotone.iterations= package includes modifications in
[[file:src/iterations.c]]: the functions have four arguments (n, x, w,
iterations_vec). The last argument is for counting the number of 
conditional iterations (in if/while blocks), in order to compare computational complexity.

** Dynamic programming

In the original monotone package legacy C functions, there is no
=isoreg_dp_weights()=, but this function is present in the forked
=monotone.iterations= code in [[file:src/legacyC.c]]. It is a new
algorithm derived from [[https://github.com/tdhock/directlabels/blob/master/src/isoreg_dp.cpp][isoreg_dp() in directlabels]], with a
corresponding instrumented version =isoreg_dp_weights_iterations()= in
[[file:src/iterations.c]].

| package             | C function for dynamic programming | notes                       |
|---------------------+------------------------------------+-----------------------------|
| monotone            | n/a                                | only PAVA functions         |
| directlabels        | [[|                     |                                    |                             |][isoreg_dp()]]                        | no weights                  |
| monotone.iterations | [[file:src/legacyC.c][isoreg_dp_weights()]]                | yes weights                 |
| monotone.iterations | [[file:src/iterations.c][isoreg_dp_weights_iterations()]]     | weights, iteration counting |
